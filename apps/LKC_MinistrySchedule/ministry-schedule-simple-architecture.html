小組/團契排班功能簡化架構

目標：平常使用只保留三個大入口；欄位長什麼樣子，由管理介面一次設定。新增分頁時先套用初始模板，之後再讓使用者客製欄位。

一、使用者主畫面

給長輩使用
新增一季聚會

選年度、季度、星期幾，系統自動產生一季日期。

貼上排班內容

貼 LINE、Word、Excel 文字，系統依目前欄位解析。

下載空白表格

下載 Excel，欄位順序依管理介面設定。

二、初始模板

新增分頁時使用

聚會型模板

小組、團契、聚會類分頁使用。

日期 主題 經文 地點 敬拜 話語分享

事工型模板

非小組團契的服事分頁使用。

日期 地點

三、新增分頁流程

先有第一版
建立新分頁 輸入 ID、顯示名稱。
→
選擇表格類型 只需要選「聚會型模板」或「事工型模板」。
系統依初始模板建立第一版 pageFieldConfig
建立分頁完成 使用者可以立刻開始新增一季聚會、貼上排班內容或下載空白表格。
→
之後再客製 需要破冰、司會、點心等欄位時，到「表格欄位設定」新增並排序。

四、表格欄位設定管理介面

給管理者使用
目前使用中的欄位，可拖曳排序
:: 日期必要
:: 地點啟用
:: 敬拜啟用
:: 破冰自訂
:: 話語分享啟用
:: 主題啟用
:: 經文啟用
管理操作
新增自訂欄位例如：點心
停用欄位不可停用日期
調整順序拖曳欄位
儲存設定套用到此分頁

五、共用資料流

所有入口共用欄位設定
pageFieldConfig 此分頁目前啟用的欄位、順序、必要欄位。
→
新增一季聚會 依欄位設定產生季度空白列。
pageFieldConfig 同一份設定。
→
貼上排班內容 / AI 解析 AI 只解析目前啟用的欄位。
pageFieldConfig 同一份設定。
→
下載空白表格 Excel 欄位與順序依設定輸出。
表格渲染、儲存、布告欄、總表也都以 pageFieldConfig.fields 為準

六、資料結構建議

可直接給 AI 
const initialFieldTemplates = {

七、給 AI 的修改需求

實作規格
  • 主畫面只保留三個大入口：新增一季聚會、貼上排班內容、下載空白表格。
  • 新增分頁時，只選擇「聚會型模板」或「事工型模板」，系統依模板建立第一版欄位設定。
  • 新增「表格欄位設定」管理介面，支援新增自訂欄位、停用欄位、拖曳排序、儲存設定。
  • optional 欄位不預先定義，由使用者按「新增欄位」後自行命名。
  • requiredFields 不可刪除或停用，目前至少保留「日期」。
  • 表格渲染、Excel 匯出、AI 解析、資料儲存、布告欄、總表都使用同一份 pageFieldConfig.fields。
  • 若分頁沒有自訂 pageFieldConfig，則使用 initialFieldTemplates 的 defaultFields。
核心原則：平常使用只問「你要做什麼」，欄位長什麼樣子交給管理介面一次設定。
